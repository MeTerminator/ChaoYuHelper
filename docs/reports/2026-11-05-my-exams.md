# 我的考试：官方 APP 页面接入

## 已实现

左侧“我的作业”下方增加“我的考试”，初始地址 `/?section=exams`。选择当前账号的缓存课程，点击“打开 APP 考试页面”，显示官方移动端考试列表。首次没有课程缓存时需到“我的课程”刷新。

官方入口已使用保存账号做只读验证：

```text
https://mooc1-api.chaoxing.com/mooc-ans/exam/phone/task-list
    ?courseId=...&classId=...&cpi=...
```

APK 中可提取 `mooc-ans/exam/phone/task-list?courseId=%s&classId=%s&cpi=%s`。输入 APK 为 `study_7.0.4_09161103.apk`；加固限制了原生业务方法体分析，不能凭命令名称确认完整监考协议。

本次不重新构造考试提交表单。后端 Playwright Chromium 按账号创建独立上下文，复制对应账号 Cookie 和 APP User-Agent，运行平台原有 H5 页面。后台以 480×800 可交互画面显示页面，点击、滚动、文字输入和有限编辑按键传入官方页面。选择题直接点击；文字题需先点击试卷内输入框，再通过旁边的文字区“输入到试卷”。计时、自动保存、手动保存和交卷由官方页面原逻辑处理；不会自动点击开始或交卷。

原生 JS `alert` / `confirm` / `prompt` 转为后台弹窗，由用户处理。`CLIENT_OPEN_URL` 在同一考试会话内打开官方页面，避免隐藏窗口。JSBridge 保留官方实现，仅补充 Android 通知入口与准备通知。

每个账号同时保留一个考试会话。切换后台页面、切换账号、关闭网页后仍保留服务端上下文；重新进入恢复当前页面，不重载试卷。要切换另一门课程，需显式关闭当前会话后重新选择。关闭会话不交卷、不暂停平台计时。服务停止或账号重新登录、删除时清理上下文；服务重启不能恢复尚未保存到平台的输入。

## 图片与监考边界

“预设图片”提供前置摄像头、后置摄像头和截屏三种配置，按账号存入现有加密数据库。支持预览、替换、移除；单张最多 8 MB / 2400 万像素，读取并转为最长边 1920 像素 JPEG，丢弃原始元数据。删除账号同时清除配置。

**这些配置目前不会自动上传。教师端抓拍请求响应、正常监考状态上报、截屏/切屏原生协议均尚未实现。** 不调用真实相机或本机截屏，不合成成功回调；原生能力请求显示在“APP 兼容状态”。H5 自身发出的平台请求仍按官方脚本运行。需要人脸识别、抓拍、录屏、直播或其他原生能力的考试可能无法进入；不能据此版本宣称完整支持监考考试。

用户当前没有可用于联调的测试考试。本次未打开任何未交考试、未开始真实考试，也未执行真实考试交卷。缺失部分需有测试考试或经过确认的请求/响应样本后继续适配。

## 隔离与生命周期

- 前端只收到渲染画面和有限状态；平台 Cookie 留在后端上下文。
- 所有考试页面网络请求校验 HTTPS、官方 `.chaoxing.com` 域名及标准端口，外域和降级地址被拒绝；页面与脚本不在后台管理员网页的 origin 中执行。
- 禁用 service worker 与下载；不开放任意 JavaScript、地址或键盘执行入口。
- 原生命令日志不记录载荷、签名 URL 或 Cookie，内存最多保留 30 条。
- Playwright 复用项目现有依赖，首次部署仍需 `uv run --locked playwright install chromium`。
