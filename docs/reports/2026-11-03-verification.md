## 已修复

| 问题 | 修复与证据 |
| --- | --- |
| 切换到荷塘等雨课堂服务器后，学习通账号可能被隐藏 | 学习通账号不受雨课堂服务器筛选；新增协议测试及浏览器跨平台切换测试 |
| 主题讨论错误使用活动 ID 作为 topicId | 优先读取原始 extraInfo.topicId，缺失时解析 URL；都缺失则提示刷新，避免请求错误话题 |
| 雨课堂 slidenav 事件解析错误，教师翻页可能回到首页 | 按原协议读取 slide.si；浏览器注入原始事件确认跳到第二页 |
| 雨课堂翻页 / 题目解锁重绘清空草稿 | 按题目保存答案、填空、图片与补交选项；翻页后检查原选择仍保留并成功提交 |
| 同账号不同课堂共享当前 bearer，可能提交到错误课堂 | 按 lessonId 隔离课堂令牌；HTTP 模拟验证答题、PPT 和定位请求分别使用对应课堂授权 |
| 课堂连接或活动请求在切换页面后返回，可能覆盖新页面 | 增加页面代次检查，旧回调不能更新当前课堂；提交时保留原课堂上下文 |
| 问卷选填题被强制作答，图片答案无文字时被阻止 | 区分问卷必答项与选填项，未答选填项不写入报文；允许只上传图片的主观题 |
| 部分无效 API 参数触发 KeyError / 服务器异常 | 对必需课程字段、活动字段、题目和操作参数返回明确的 422；不存在账号返回业务错误 |
| 缺少或为 null 的平台结果可能计为成功 | 拒绝无效平台响应，批量操作将无返回值记录为失败 |
| 新数据目录直接使用雨课堂时设备 ID 可能为空 | 设备 ID 在基础 Provider 初始化时生成并持久化 |
| 页面重绘删除事件来源后，刷新通知触发隐藏的服务端异常 | 使用稳定的客户端根上下文执行异步界面操作；浏览器集成测试同时检查服务端日志无 Traceback |
| 环信旧账号的延迟消息可能归入新账号 | 每个连接绑定账号 ID；后端丢弃不匹配的延迟消息；消息 attachment 为 JSON 字符串时也能解析 |
| 环信云端漫游失败时，本地历史也无法查看 | 云端失败显示提示并继续展示本地已接收消息；浏览器模拟漫游拒绝后验证本地消息可见 |
| PPT 下载统一写为 .png，即使原图为 JPEG | 使用图像实际格式生成扩展名；单页改为后端获取后下载，不依赖跨域浏览器 download 属性 |
| 空签到码 / 未知签到类型仍会请求平台 | 本地提前校验并阻止；测试确认不发出上游请求 |

验证覆盖：

- 加密存储、Cookie 域与路径持久化、平台 / 服务器隔离。
- 学习通 App 登录报文 AES、设备信息 RSA、返回 clientId 公钥解密、IM 专用凭据 DES 解密及登录 Cookie 流转（全部为测试凭据和模拟响应）。
- 学习通五类签到请求、问卷重复字段、特殊字符、随堂练习答案与图片附件、结束状态。
- 雨课堂短信前置验证、课堂授权、跨课堂令牌隔离、补交报文。
- 浏览器课程刷新、设置、签到、投票、问卷、评分、讨论、选人结果与操作记录。
- 浏览器雨课堂连接、教师翻页事件、草稿保留、题目解锁、答案提交。
- 浏览器环信消息接收入口和云端历史失败时的本地历史回退。
- REST 鉴权、账号列表脱敏、无效参数响应；移动端布局。

原始 Flutter 项目保持未修改。常规后端没有装载测试数据或模拟 Provider。
