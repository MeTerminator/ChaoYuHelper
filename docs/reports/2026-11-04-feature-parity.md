# 原项目功能逐项补齐记录

> 历史验证记录：文中只读模式后续已按用户要求移除，当前启动方式见根目录 README。

本轮以用户列出的功能及 `course_helper/lib/` 源码为对照。原项目目录保留，未修改。项目根目录是课程助手浏览器版。

## 核对结果

| 用户要求 | 当前实现及入口 | 验证证据 |
| --- | --- | --- |
| 五种签到、验证码、人脸 | 活动 → 查看；普通 / 照片、二维码、手势、位置、签到码，逐账号图片、验证码和人脸参数 | 五种请求的 HTTP 模拟测试；验证码和人脸代码与原协议核对，未真实提交 |
| 选人及选中通知 | 选人窗口每 3 秒读取结果；新选中账号显示持续通知，可启用桌面通知；关闭窗口或切换账号停止检查 | 浏览器模拟教师新增选中账号，验证通知；首次列表与重复去重单测 |
| 主题讨论 | 主题、回复列表、匿名选项与多账号发表 | 主题 ID 解析及浏览器模拟回复 |
| 评分 | 总分、分项和评语 | 浏览器模拟评分；对照原评分字段 |
| 投票 | 单选 / 多选，选项提交 | 浏览器模拟作答；对照原投票字段 |
| 问卷 | 必答 / 选填、多选及文字回答 | HTTP 模拟重复表单字段和选填省略；浏览器模拟提交 |
| 随堂练习自动填入提交 | “填入参考答案并提交”，补全未答题目后提交；无参考答案时要求填写 | 选择 / 多选 / 填空 / 文字参考答案单测；浏览器一键提交；图片附件报文测试 |
| 作业 | 列表、已完成 / 待批阅记录；常见题型、排序 / 连线、多编辑器；分页、图片 / 文件附件、当前账号加密草稿、提交 | 真实只读读取作业列表及已完成记录（数量省略）；模拟表单签名、分页合并、题量校验；浏览器完成七道不同题型、附件上传、跨页草稿恢复及手动提交 |
| 群聊签到及参与列表 | 群聊与消息 → 活动 ID 或消息入口；参与列表 | 浏览器打开群聊签到及参与列表；HTTP 路径与原实现一致 |
| IM 协议 | 环信登录、消息、群聊和历史，Linux 设备类型 2，本地加密历史回退 | 固定 SDK 源码核对 Provision.osType；模拟 SDK 验证账号切换、旧回调隔离及通知；未登录真实 IM |
| 雨课堂动态二维码签到 | 顶部扫码入口、相机 / 图片识别，保留动态 URL 并获取对应课堂授权 | HTTP 模拟扫码 → 入课堂顺序、原 URL 和课堂令牌；二维码图片识别单测 |
| 整份 PPT | 课堂内自由 / 跟随翻页、缩略图、全屏、备注、单页和整份下载 | 浏览器模拟两页课堂、全屏及教师翻页；校验整份 ZIP 页数、图片格式与高分辨率来源；未真实入课堂 |
| 雨课堂课堂答题及延时 | 多种题型、图片、草稿；倒计时、教师延时、时间线原题时间、超时补交 / 手动重试 | 浏览器模拟翻页和重连保留草稿、延时事件；HTTP 模拟重试报文与跨课堂令牌隔离 |

原 README 的作业项是待办，本版已新增独立作业模块，并补齐此前缺少的附件、分页、排序 / 连线及多编辑器支持。上表逐项覆盖用户要求的功能。平台定制控件或后续协议变化可能超出当前规则，届时会明确拒绝不完整提交；这不是对所有学校页面变体的兼容性保证。

## 修复的行为缺口

- 合并网页端独有的活动，保留讨论等活动的元数据，新增按功能筛选及数量。
- 选人结果由手动刷新改为仅在窗口存续期间轮询通知；平台尚未选人时的 `result=0` 识别为空列表。
- 随堂练习增加一键填入并提交，保留手工答案，不猜测平台未给出的参考答案。
- 雨课堂重连保留草稿和题目状态；处理 `extendtime`，时间线补交使用原题 `dt`，课堂结束仍可按平台规则尝试补交。
- IM 修复默认 Web 设备类型与原 Linux 类型不一致的问题；旧账号连接、消息和桌面通知均隔离。

## 测试边界

本轮最终检查：`ruff check app main.py scripts tests` 通过；`pytest -q` 为 **54 passed**。浏览器流程包含原有交互、新选中通知、群聊参与列表、作业草稿恢复及模拟提交、雨课堂延时和重连草稿。文档相对链接、macOS 启动脚本语法及真实只读服务 `/health` 也通过。

所有修改类接口的验证使用临时数据库、模拟 HTTP 或模拟 SDK。没有对真实账号执行签到、入课堂、扫码、答题、作业作答启动 / 保存 / 提交、消息发送、评分、回复、人脸提交或上传。真实账号只增加作业列表和已提交记录读取。

真实只读模式继续阻止进入作业作答页，以免启动平台计时。测试成功证明所覆盖的报文和浏览器流程，不等于真实课堂已接受业务提交。


## 本轮收尾复核

- 作业部分新增长期保留的模拟页面 `tests/fixtures/homework.html`，覆盖七种交互；不含真实作业内容、账号或令牌。
- `tests/test_homework_complete.py` 验证跨页合并、外层容器去重、内部选项值、账号和题目级附件隔离、平台已有答案与图片保留，以及只读重定向拦截。
- `tests/test_ppt_export.py` 检查 ZIP 中每一页的内容与真实图片扩展名，高分辨率地址优先；缺少任一页图片时明确报错，不生成看似完整的部分文件。
- 更新后的只读保护再次验证作业列表与已完成记录读取；公开报告省略真实业务数量，未执行真实提交。
- 修改类接口按用户要求仅做代码核对与模拟测试；未尝试真实提交，也未为读取 PPT 而调用课堂 checkin。
