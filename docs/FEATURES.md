# 功能说明

## 平台与账号

- 学习通：网页登录、原 App 密码登录、短信、二维码、Cookie 导入。
- 雨课堂：网页密码登录、原 App 登录、短信、微信 / APP 二维码、Cookie 导入。
- 雨课堂服务器：普通 `www.yuketang.cn`、荷塘 `pro.yuketang.cn`、长江 `changjiang.yuketang.cn`、黄河 `huanghe.yuketang.cn`。
- 账号按平台、服务器和 UID 隔离。雨课堂会保留登录方式，分别使用 Web / App 会话头；课堂授权进一步按 lessonId 隔离。

密码登录默认勾选“使用网页登录接口（推荐）”。平台要求腾讯验证码、学习通验证码或新设备验证时，按页面提示由用户完成。二维码登录需生成二维码，授权后点击“检查授权”。

## 功能与入口

| 功能 | 入口与行为 |
| --- | --- |
| 课程与活动列表 | 我的课程；手动刷新、搜索；学习通合并 App / Web 活动数据（包含仅网页端返回的条目），按功能筛选，雨课堂标记正在进行的课堂 |
| 课程设置 | 课程卡片 → 课程设置；教室、地址、经纬度、当前位置、地图选点与照片 |
| 普通 / 拍照、二维码、手势、位置、签到码 | 活动 → 查看；可选择操作账号、公共或逐账号照片、验证码与人脸校验 |
| 签到参与列表 | 签到详情；读取平台返回的已签到 / 未签到信息 |
| 群聊签到 | 群聊与消息 → 群消息活动，或填写活动 ID |
| 选人 | 查看结果，标记本地已保存账号；打开选人窗口后每 3 秒检查新选中账号，窗口内通知及可选桌面通知，关闭后停止 |
| 主题讨论 | 展示主题、回复，填写回复，平台允许时可匿名 |
| 评分 | 总分、分项评分及评语 |
| 投票、问卷 | 单选、多选、判断、文字题；问卷区分必答与选填 |
| 随堂练习 | 选择、填空、文字及图片答案；可填入平台提供的参考答案；支持一键填入并提交，不覆盖已填写答案，平台未提供答案的题目需要手动补全 |
| 作业 | 课程 → 课程作业；列表与题目分页、已提交记录、选择 / 填空 / 判断 / 主观 / 排序 / 连线 / 多编辑器作答、图片和文件附件、加密草稿及手动提交 |
| 学习通消息 | 群聊 / 私聊会话同步、头像及昵称、文字消息发送、每会话草稿、云端消息漫游分页、本地加密消息缓存、未读数量及收到的已读回执展示、内部同步命令过滤、课堂活动入口、图片预览及媒体链接、桌面通知 |
| 雨课堂签到 | 动态二维码入口、课堂中的位置签到表单 |
| 雨课堂 PPT | WebSocket、教师翻页跟随、自由翻页、缩略图、全屏、备注、单页或整份下载；整份导出不静默遗漏缺图页面 |
| 雨课堂答题 | 选择、投票、填空、主观及图片答案；翻页与重连保留题目草稿；倒计时、教师延时、超时自动选用补交接口及原题时间参数 |
| 雨课堂时间线 | 展示课堂事件，切换对应 PPT 或题目 |
| 操作记录 | 查看手动批量操作的逐账号成功 / 失败结果 |

原项目的作业功能是未勾选的待办项；本版新增独立作业模块。暂未增加服务端定时检查、AI 接入或无人值守提交。作业按当前账号加载签名表单；不识别的表单、未完整加载的题目和不支持的复杂题型会明确阻止提交。支持平台提供链接的跨页加载，并按题目 ID 验证完整性；附件与草稿按账号和题目隔离。重新进入作答时恢复平台已有答案，已有图片和文件默认保留，也可手动移除。平台定制控件或页面结构变化超出当前解析规则时，会提示并阻止不完整提交。

## 兼容性与验证范围

- 消息服务由后端在启动时自动连接已保存的学习通账号，按账号共享连接并自动重连、续期。打开“群聊与消息”自动接入，所有网页复用后端连接；关闭网页不影响消息接收。连接后会后台缓存可读取历史中的图片和头像，新消息图片也会自动缓存；网页提前加载并从共享缓存显示。缓存有容量和有效期限制，首次预取完成前仍可能需要等待。部署时需要安装 Playwright Chromium。
- 消息接入已按当前官方 Web IM 源码核对：从学习通获取临时 Token、保留 Web 设备类型 `16`，使用官方环信 REST 地址。SDK 固定为 4.24.0；官方网页使用 4.24.3.1 模块版。已用真实账号验证群聊及私聊读取、头像昵称及活动卡片。发送逻辑已实现，按用户要求未做发送测试。云端漫游受平台保留期限与权限限制；失败时保留本地消息，不能恢复平台已过期或无权限的历史。
- 相机、定位及通知由浏览器权限控制；远程访问时相机和定位通常需要 HTTPS。二维码支持相机画面和上传图片，不依赖浏览器 `BarcodeDetector`；地图使用在线 OpenStreetMap 瓦片。
- 移动端前台保活、手机系统权限管理和 APK 更新器没有对应的浏览器开关。课堂连接在页面存续时运行，退出课堂或关闭页面会停止连接。
- 是否允许补交、签到是否有效、活动是否结束以及人脸 / 图片是否被平台接受，均以平台返回为准。
- 真实只读测试覆盖学习通及长江雨课堂的登录、资料和课程查询，以及学习通作业列表、已完成记录读取；其他功能的自动化验证使用模拟平台，未向真实课堂提交。

本轮逐项迁移状态和证据见 [完整功能补齐记录](reports/2026-11-04-feature-parity.md)。
