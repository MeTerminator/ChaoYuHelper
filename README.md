# 课程助手

课程助手支持学习通、雨课堂课程管理。浏览器呈现界面，Python 后端管理账号会话、课程数据与平台请求。项目代码已直接放在当前根目录。

## 快速开始

使用 [uv](https://docs.astral.sh/uv/)；项目默认 Python 3.12，代码支持 Python 3.11–3.13。

```bash
cd ChaoYuHelper
uv sync --locked
uv run --locked playwright install chromium
uv run --locked python main.py
```

消息服务在后端启动时自动连接已保存的学习通账号，断线后按 2–60 秒退避持续重连，并自动更新即将过期的消息凭据。同一账号的所有网页共享后端连接；打开“群聊与消息”会自动接入并同步会话，关闭网页不会断开后端连接。新增或重新登录账号后也会自动连接。消息仍仅在用户点击发送或按 Ctrl+Enter 时发送。连接后会后台预取本地记录及可读取的云端历史中的消息图片和头像，新图片也会自动缓存；所有网页共用 `data/cache/im/` 下的图片缓存，滚动时优先读取缓存。缓存最多 256 MB / 4096 张、保留 7 天，单张上限 8 MB；超出容量会清理旧图片。首次预取尚未完成或平台图片不可访问时，仍需等待下载或手动重试。

服务启动时不会自动打开浏览器。请手动在浏览器访问 [课程助手](http://127.0.0.1:8080)。

首次访问会进入“设置管理员”，填写管理员名称及至少 8 位的密码，确认后登录即可进入后台。后续访问需要登录；左侧导航的“系统设置”可以修改名称和密码，修改时需验证当前密码，保存后所有设备需要重新登录。点击“退出登录”可结束当前浏览器会话。

## 使用方式

1. 顶部选择学习通或雨课堂。雨课堂账号须选择所属服务器：普通、荷塘、长江或黄河，各服务器会话独立。
2. 进入“账号管理”添加账号。密码登录默认采用网页接口；验证码由用户手动完成，也支持短信、二维码、Cookie 等方式。
3. 点击“刷新课程”。学习通可通过课程卡片的“查看活动”和“课程作业”分别进入活动页与作业页，作答记录和作答也有独立页面地址；雨课堂可查看正在进行的课堂、PPT 和课堂时间线。
4. 正常模式下，手动提交前选择操作账号，完成后检查逐账号结果与操作记录。

支持多账号、课程设置、五类签到、选人、讨论、评分、投票、问卷、随堂练习、作业列表与作答、群聊消息，以及雨课堂 PPT 和课堂答题。完整说明与兼容性边界见 [功能说明](docs/FEATURES.md) 和 [逐项迁移记录](docs/reports/2026-11-04-feature-parity.md)。作业支持分页、图片和文件附件、排序与连线、多编辑器作答及加密草稿。尚未添加服务端定时检查、AI 答题和无人值守提交。

学习通作业 HTML 会清理平台样式、脚本和重复隐藏文本，统一展示题干、选项、答案与解析。作业图片通过需要管理员登录的同源后端接口加载，使用对应学习通账号的登录态；图片缓存保存在 `data/cache/`（设置 `COURSE_HELPER_DATA` 时跟随该目录），按账号隔离，有效期 1 小时，上限 64 MB / 512 张，单张图片限制 8 MB，服务重启后可复用未过期缓存，过期或超出容量的缓存自动清理。

## 配置与数据

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | 后端监听地址 |
| `--port` | `8080` | 监听端口 |
| `--no-open` | 无需指定 | 兼容旧命令；服务始终不自动打开浏览器 |
| `COURSE_HELPER_DATA` | 项目下 `data/` | 加密数据库、密钥及 REST API Token 的目录 |
| `NICEGUI_STORAGE_PATH` | 当前工作目录下 `.nicegui/` | 浏览器界面偏好等持久化状态 |

`data/course_helper.db` 存储管理员名称、加盐 scrypt 密码哈希、管理员登录会话，以及加密的平台会话、课程缓存和记录。管理员密码不以明文保存，平台登录密码不保存；Cookie、IM 专用凭据按会话加密存储。`data/.key` 是对应加密密钥，备份时须将整个 `data/` 一起备份。`.nicegui/` 保存界面偏好，可与数据一起备份。这两个目录均已保留并排除版本控制。

当前是单管理员工作空间。浏览器后台、接口文档及界面连接均需要管理员登录，会话有效期为 12 小时。`/health` 保持公开；`/api/*` 继续独立使用 Bearer Token，浏览器登录不能代替 API Token。如需局域网或远程部署，可设置 `--host 0.0.0.0` 并使用 HTTPS 反向代理。
